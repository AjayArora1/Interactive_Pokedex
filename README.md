# Interactive Pokedex

A React-based interactive Pokédex powered by the PokéAPI.

## ✨ Features

- 🔍 Search for Pokémon
- 📊 View Pokémon stats
- ✨ Toggle shiny sprites
- 🔊 Play Pokémon cries
- 🔥 Explore Pokémon types
- ⚔️ Compare Pokémon stats side by side
- 🧬 View evolution chains
- 🚀 And more!

- React
